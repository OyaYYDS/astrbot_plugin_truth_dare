# 🎯 选人器（astrbot_plugin_truth_dare）

> QQ 群随机选人插件：报名 → 3D 滚轮动画选人 → 艾特点名。支持「一人 / 两人 / 纯文本」三种模式、深浅双主题、多群隔离、历史统计。

## ✨ 功能特性

- **报名制游戏**：群成员 @机器人 报名，显示名可自定义；名单编号自动排序，退出自动补位
- **三种抽取模式**（可配置 + 群内指令切换）：
  - **双人**：两幕动画——3D 菱形滚轮选「回答者」→ 昵称首字横盘选「提问者」→ 红框展开揭开全名
  - **单人**：仅滚轮选回答者（经典单幕）
  - **文本**：不生成 GIF，纯文本极速播报（性能敏感场景）
- **两幕动画**（560×560，QQ 气泡内完整播放一遍）：
  - 第一幕：竖向 3D 透镜滚轮（中心格放大 2.0x、三段连续减速无卡顿）→ 金框金字定格 →「回答者」垫字渐显
  - 第二幕：其他行淡出 → 金框上移 → 首字横盘滚动（金属红指示框）→ 选中格双轴展开至金框同尺寸 → 全名滚动式揭开并放大 →「提问者」垫字渐显
- **深色 / 浅色双主题**（浅色版白底斑马纹 + 白数字格）
- **连中降权**：权重 = 1/(1+连中次数×系数)，被选中者下一局概率降低
- **多群隔离**：每群独立名单与历史，互不干扰
- **准入模式**：宽松（黑名单，默认全开）/ 严格（白名单，仅登记群可玩）
- **数据统计页**：全群总览（跨群排行、三卡片、趋势线图）+ 单群详情 + 最近 20 局记录
- **群内查询指令**：排行榜、群排行榜、状态、帮助一应俱全
- **细节打磨**：emoji 昵称渲染过滤（防方框）、防刷屏冷却、真艾特点名（含开关）、标签文字可自定义（≤3 汉字）

## 📦 安装

1. 插件市场搜索「**选人器**」安装；或
2. 手动克隆：将本目录放入 AstrBot 的 `data/plugins/` 下（目录名保持 `astrbot_plugin_truth_dare`）

插件本体不打包字体，运行时按系统字体链解析（微软雅黑 Bold 优先），体积 <100KB。

## 🎮 使用方法

```
1. 报名：@机器人 参加选人器 名字
2. 开转：@机器人 选人器开始
```

开转后机器人发送：带编号名单 → 动画 GIF（或纯文本）→ 独立艾特消息点名。

## 📋 指令列表

### 所有人

| 指令 | 说明 |
|---|---|
| `参加选人器 [名字]` | 报名（可自定义显示名） |
| `选人器开始` | 开始抽选 |
| `选人器玩家` | 查看名单 |
| `选人器退出` | 退出游戏 |
| `选人器重置` | 清空名单 |
| `选人器人数 [1\|2]` | 切换抽取人数（不加参数查看当前） |
| `选人器动画 开\|关` | GIF / 纯文本切换（不加参数查看当前） |
| `选人器排行榜` | 本群战绩统计 |
| `选人器群排行榜` | 全群战绩统计 |
| `选人器状态` | 本群状态自查 |
| `选人器帮助` | 玩法与常用指令说明 |

### 管理员

| 指令 | 说明 |
|---|---|
| `选人器指令` | 全部管理指令清单 |
| `选人器玩家移除 名字/QQ` | 移除指定玩家 |
| `选人器开启` / `选人器关闭` | 本群玩法开关 |
| `选人器群添加` / `选人器群删除` | 群登记管理（删除=清空数据） |

## ⚙️ 配置项

| 配置 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 准入模式 | 开关 | 关（宽松） | 开 = 白名单（严格） |
| 整体主题 | 下拉 | 深色 | 深色 / 浅色 |
| 抽取人数 | 下拉 | 两人 | 两人 / 一人 |
| 文本模式 | 开关 | 关 | 开 = 不生成 GIF，纯文本极速 |
| 动画标题文字 | 文本 | 选人器 | ≤10 字符，留空回退默认 |
| 「第一人」标签文字 | 文本 | 回答者 | 1~3 汉字 |
| 「第二人」标签文字 | 文本 | 提问者 | 1~3 汉字 |
| GIF 总时长（毫秒） | 数字 | 6500 | 按比例缩放全部帧 |
| 连中降权系数 | 数字 | 1.5 | 权重 = 1/(1+连中×系数) |
| 艾特提醒 | 开关 | 开 | 关 = 不发艾特消息 |
| 报名人数上限 | 数字 | 20 | 必须 ≥2，不设上限 |

## 📊 统计页

插件 UI 界面 →「数据统计」：

- **主页（默认）**：全群总览——参与群聊 / 总玩家 / 总游玩局数三卡片、跨群玩家总排行（按 QQ 合并，前 10）、跨群最近 20 局（带群名片）、每日局数趋势（7/30 天）
- **单群详情**：点击左侧群卡片查看，支持 总/日/周/月/年 时间范围过滤
- 群别名设置、添加/重置/删除群（均有二次确认弹窗）


## ✅ 兼容性

- **AstrBot** ≥ 4.16
- **平台**：OneBot v11（NapCatQQ 实测）等所有支持图片消息的平台
- **QQ 客户端动画行为**（实测结论）：GIF 不写 NETSCAPE 循环扩展时 QQ 播放一遍后停；动图体积 100KB~1MB 均可正常播放
